# WalkDog – 산책형 가상 반려견 앱 기획서 (최종안)

> 목표: “많이 걸을수록 더 행복해지는 **가상 강아지**”를 통해 사용자의 **산책 빈도와 야외 체류 시간**을 자연스럽게 늘린다. 실제 반려동물을 키우기 어려운 사람에게 **정서적 만족감**을 제공한다. (플랫폼: iOS/Android, 기간: 4–5주)

---

## 1) 제품 개요
- **핵심 컨셉**: 걸음수가 곧 강아지의 행복과 보상이 되는 **워킹 톰라고치**.
- **핵심 루프**: 산책 시작 ▶ 걸음수 적립 ▶ 간식/배지 획득 ▶ 강아지 행복도 상승 ▶ 강아지의 AI 대화·칭찬 ▶ 재방문 유도.
- **차별점**: (1) 온디바이스 **로컬 LLM**로 반응형 대화, (2) **클라우드 이미지 생성**으로 사용자 취향의 강아지 스티커/포즈 제작, (3) 선택형 **실외 모드(안티치트)**.

### 성공 지표(KPI)
- D1/D7 잔존, 주간 산책 총 시간(분), 일평균 걸음수(+%), 일평균 앱 재방문 수, 생성 스티커 저장률.

---

## 2) 사용자 페르소나 & 시나리오
- **페르소나 A – 기숙사생**: 반려동물 못 키움. “하루 30분 걷기 습관”이 필요.
- **페르소나 B – 재택 근무자**: 장시간 실내. 산책 동기부여와 소소한 재미 원함.
- **핵심 시나리오**: 점심 산책 15분 → 앱에서 ‘산책 시작’ → 걸음 적립 → 간식 2개 획득 → 강아지에게 간식 → 행복도 72→86 → AI가 칭찬 멘트 → 저녁에 배지 확인 및 스티커 저장.

---

## 3) 기능 범위 (MVP / 확장)
### MVP
1. **산책 트래킹(걸음 기반)**: pedometer 연동, 실시간 걸음수·속도 표시.
2. **실외 모드(옵션)**: 걸음수 + 위치 변화 조건 동시 만족 시 보상(안티치트).
3. **강아지 행복도/보상**: 간식/배지/미션, 일간/주간 목표.
4. **커스터마이즈**: 이름, 색상/무늬, 액세서리.
5. **AI 대화(온디바이스)**: 강아지 성격/행복도 반영, 짧은 칭찬·동기 멘트.
6. **이미지 생성(클라우드)**: 품종·색·액세서리 반영한 스티커 512px 생성, 캐시.
7. **알림**: 오늘 남은 목표, 연속 산책 스트릭 리마인더.

### 확장(선택)
- 포즈 2종(정면/걷기) 이미지, 공기질/날씨 기반 산책 타이밍 추천, 주간 리포트, AR 셀카, 위젯·워치 동기화.

---

## 4) AI 아키텍처 (하이브리드)
- **로컬 LLM(대화)**: *Qwen2.5-3B-Instruct, q4(MLC)* 권장. 온디바이스 실행, 50–100 토큰 응답, 프라이버시 보장.
- **클라우드 이미지 생성**: Google **Gemini 이미지(일명 “나노바나나”)** 또는 동급 서비스. Firebase Functions 프록시를 통해 호출(키 보호/요금제한/캐시 처리). 결과는 **WebP 512px, 배경 투명(가능 시)**, **seed=petId**로 일관성 확보.
- **폴백**: 오프라인/실패 시 **벡터 아바타** 사용. 대화 실패 시 간단 규칙봇.

### 프롬프트 규칙(개요)
- **대화(시스템)**: `너는 {name}({breed}) 강아지. 현재 행복도={h}/100. 한국어, 1문장, 35자 이내, 상냥한 말투.`
- **이미지(텍스트)**: `{breed} dog, {color} coat, {accessory}, cute sticker, front view, simple shading, white background, 2D flat` + `seed=petId`.

---

## 5) 산책 판정 & 보상 설계
### 센서/판정
- **기본**: 걸음수(pedometer).
- **실외 모드(옵션)**: 아래 3조건 만족 시 유효 샘플로 인정:
  1) 위치 샘플 간 거리 ≥ 60m, 2) 샘플 간 시간 ≥ 30초, 3) 추정 속도 ≤ 8 km/h.
- **배터리 정책**: 포그라운드 산책 시에만 GPS 사용, 백그라운드에선 걸음수만.
- **안티치트**: `in_vehicle` 활동 감지 시 무효, 가속 패턴 이상치 필터.

### 보상/행복도 공식(기본값)
- **간식 지급**: `300 걸음 = 간식 1개`(Remote Config로 조정).
- **행복도 증가**: `100 걸음 = +2`, **간식 사용**: `+8`, 상한 `100`.
- **일일 디케이**: 자정 기준 `-10`(최소 0).
- **실외 보너스**: 실외 모드 유효 샘플이면 **보상 +20%**.
- **배지 예시**: 누적 1천/5천/1만 걸음, 행복도 90+, 7일 스트릭.

### 미션(예)
- “연속 7분 걷기”, “공원 입구까지 300m 걷기”, “산책 후 물 마시기 체크”. 문구는 로컬 LLM이 짧게 생성.

---

## 6) 화면 설계(요약)
1. **홈**: 강아지 아바타(스티커/벡터), 행복도·오늘 걸음·간식, 산책 시작/정지, 간식 주기, AI 대화창.
2. **커스터마이즈**: 이름/색/액세서리, (선택) 품종 선택 + 스티커 생성/재생성.
3. **배지/기록**: 누적 걸음·배지 목록, 최근 산책 로그(간단 통계).
4. **설정**: 실외 모드 토글, LLM/이미지 네트워크 사용, 알림, 데이터 초기화.
5. **온보딩**: 권한 안내(활동/동작, 위치 선택), 모델 다운로드(대화 LLM), 사용법 튜토리얼.

---

## 7) 데이터 모델(요약)
- **Pet**: `id, name, breed, color, accessory, happiness(0–100), treats, stepsToday, totalSteps, lastUpdate, stickerPath`
- **Settings**: `isOutdoorMode, localLLMEnabled, cloudImageEnabled, stepPerTreat, notifications`
- **WalkLog**: `id, date, steps, duration, outdoorSamples, rewardsGained`
- **Achievement**: `code, title, achievedAt`

(저장: 로컬 DB – Isar/Hive. 민감 정보/PII 저장 없음.)

---

## 8) 비동기/캐시/오프라인
- **LLM 모델**: 앱 최초 실행 시 다운로드(진행률/취소/재개). 완료 전 대화는 규칙봇으로 임시 대응.
- **이미지 캐시**: `appDir/pets/{petId}.webp`. 존재 시 재생성 금지(재생성 버튼으로만 교체).
- **오프라인 UX**: 네트워크 없음 → 벡터 아바타, 대화는 로컬로 동작.

---

## 9) 권한 및 정책
- **Android**: `ACTIVITY_RECOGNITION`(필수), `ACCESS_FINE_LOCATION`(실외 모드시), 포그라운드 서비스 알림(선택).
- **iOS**: `NSMotionUsageDescription`, `NSLocationWhenInUseUsageDescription`.
- **스토어 주의**: 백그라운드 위치 수집 금지(본 앱은 포그라운드만), 아동 대상 아님 명시, 사용자 제작 이미지의 부적절 콘텐츠 서버 측 필터링.

---

## 10) 성능·배터리·품질
- **모델 크기/메모리**: q4 3B급 ≈ 0.7–1.2GB. 응답 60토큰 제한, 스트리밍 UI.
- **발열 관리**: 장문 생성 금지, 화면 꺼짐 시 즉시 중단.
- **배터리**: GPS 샘플링 간격 완화(30–60초), 걷기 중 화면 밝기 제한 안내.
- **로깅**: 로컬 로그 + (선택) Crashlytics/Analytics.
- **Remote Config**: `stepPerTreat, outdoorBonus, decay, missionOn/off, imageOn/off` 등 즉시 조정.

---

## 11) 일정(4–5주)
- **1주**: 와이어프레임, 데이터모델, 기본 UI, 커스터마이즈(벡터).
- **2주**: pedometer 연동, 보상/행복도/배지, 실외 모드·안티치트.
- **3주**: 로컬 LLM(다운로드/추론), 대화 UX, 알림/미션.
- **4주**: 클라우드 이미지 생성(프록시/캐시), 오류 처리, 접근성/다크모드, 테스트/스크린샷.
- **(+1주)**: 버그픽스, 발표 데모 스크립트·영상.

---

## 12) 테스트 계획
- **단말 매트릭스**: iOS(최소/최신), Android(중저가/고성능). 보행자/자전거/차량 상황 시뮬레이션.
- **기능 케이스**: 권한 거부/허용, 오프라인 시작, GPS 끊김, 모델 다운로드 실패/재개, 이미지 생성 실패 폴백, 실외 모드 속도 초과 무효 처리.
- **수용 기준**: 10분 산책 시 간식 ≥2개, 행복도 상승, 배지 1개 달성, 이미지 1장 생성·캐시 확인.

---

## 13) 보안·프라이버시
- **키 보호**: 이미지 생성 API는 **Functions 프록시**만 사용(직접 호출 금지), 레이트리밋/쿼터.
- **데이터 최소 수집**: 사용자 식별/PII 저장 안 함. 산책 로그는 로컬에만 저장(옵션 백업 없음).
- **콘텐츠 안전**: 사용자 업로드·프롬프트에 대한 서버 측 필터링.

---

## 14) 라이선스/법적 고려
- **로컬 LLM 가중치**: 오픈 가중치 사용(Qwen2.5-3B 등). 라이선스 표기, 앱 내 ‘오픈소스 고지’ 페이지 제공.
- **이미지 생성물**: 제공자 약관 준수(워터마크/SynthID 등 정책 확인). 사용자 생성 이미지의 권리 고지.

---

## 15) 향후 로드맵
- AR 산책 셀카, 소셜(친구와 주간 걸음 대결), 커뮤니티 챌린지, 반려동물 백과(품종 카드), 웨어러블 연동.

---

## 16) 데모 시나리오(발표용)
1. 온보딩: 권한 허용, 로컬 LLM 다운로드 완료.
2. 커스터마이즈: 품종/색/액세서리 선택 → 스티커 생성(1회) → 저장.
3. 산책 시작: 3–5분 걷기(에뮬레이터엔 시뮬레이터 제공) → 간식 획득 팝업.
4. 강아지에게 간식 → 행복도 상승 → AI 칭찬 멘트 노출.
5. 배지 화면에서 ‘1천 걸음’ 달성 예시 확인.

---

### 부록 A: 설정 기본값(권장)
- `stepPerTreat=300`, `hGainPer100Steps=+2`, `hGainPerTreat=+8`, `dailyDecay=10`, `outdoorBonus=1.2`, `gpsSampleSec=30`.

### 부록 B: 실패 폴백 트리
- 이미지 생성 실패 → 벡터 아바타 표시 + “재시도” 버튼.
- 로컬 LLM 오류 → 규칙봇 답변 + 재시작 안내.
- 권한 거부 → 온보딩 리마인더 카드 + 설정으로 이동 CTA.

---

**요약**: WalkDog은 **로컬 LLM 대화 + 클라우드 이미지 생성**의 하이브리드로, 4–5주에 충분히 완성 가능한 산책 동기부여 앱이다. 최소 범위만으로도 “걷기→보상→칭찬→재방문”의 선순환 루프를 구현하며, 확장 여지도 크다.
