
  📋 WalkDog 통합 테스트 체크리스트 (Week 1-3)

  🎯 테스트 개요

  - 테스트 환경: iPhone (실기기)
  - 빌드 타입: Release
  - 테스트 시간: 약 30-40분 예상
  - 테스트 순서: Week 1 → Week 2 → Week 3

  ---
  📱 Week 1: 기초 UI 및 화면 테스트 (10분)

  - 펫 아바타:
    - 강아지 이모지가 표시되는가? - yes
    - 펫 이름이 올바르게 표시되는가? - yes
    - 펫을 터치하면 반응하는가? - yes
  - 펫 상태 위젯:
    - 레벨 표시 (Lv. 1) - yes
    - 경험치 바 표시 - yyes
    - 행복도 바 표시 (0-100) - yes
    - 간식 개수 표시 - yes
    - "간식 주기" 버튼 표시 - yes
  - AI 대화 말풍선: 인사 메시지가 표시되는가? - yes
  - 산책 버튼: "산책 시작" 버튼이 중앙에 크게 표시되는가? - yes
  - 미션 요약 위젯: 오늘의 미션이 표시되는가? - yes
  - 연속 산책 위젯: 연속 일수가 표시되는가? - yes
  - 주간 차트: 막대 차트가 표시되는가? - yes

  1.3 Bottom Navigation (2분)

  - 홈 탭: 홈 아이콘 클릭 시 홈 화면으로 이동 - yes
  - 산책 탭: 산책 아이콘 클릭 시 산책 화면으로 이동 - yes
  - 커스터마이즈 탭: 커스터마이즈 아이콘 클릭 시 커스터마이즈 화면으로 이동 - yes
  - 설정 탭: 설정 아이콘 클릭 시 설정 화면으로 이동 - yes

  1.4 커스터마이즈 화면 (1분)

  - 6개 액세서리 표시:
    - 모자
    - 안경
    - 목걸이
    - 배경
    - 옷
    - 신발
  - 각 액세서리 클릭 가능한가? - yes

  1.5 설정 화면 (2분)

  - 게임 설정:
    - 일일 걸음수 목표 설정 (1,000 - 30,000)
  - AI 설정:
    - AI 대화 활성화 토글
  - 알림 설정:
    - 산책 리마인더 토글 ?
    - 행복도 낮음 알림 토글 ?
    - 미션 만료 알림 토글 ?
  - 앱 설정:
    - 다크 모드 토글 (라이트/다크 전환 확인)
    - 버전 정보 표시

  🚶 Week 2: 센서 및 게임화 기능 테스트 (15분)

  2.1 권한 요청 및 초기화 (2분)

  - 걸음수 권한: 앱 시작 시 "피트니스 및 활동" 권한 요청이 나타나는가?
    - 권한 허용 시 정상 동작
    - 권한 거부 시 안내 메시지 표시
  - 위치 권한: 산책 시작 시 위치 권한 요청이 나타나는가?
    - "앱 사용 중에만 허용" 선택 가능

  2.2 산책 기능 테스트 (5분)

  - 산책 시작:
    - 홈 화면에서 "산책 시작" 버튼 클릭
    - 산책 화면으로 이동하는가?
    - 타이머가 00:00에서 시작하는가?
    - 실시간 걸음수가 표시되는가?
    - GPS 상태 위젯이 표시되는가?
  - 실시간 걸음수 증가:
    - 아이폰을 들고 걷거나 흔들면 걸음수가 증가하는가? (10-20걸음 테스트)
    - 홈 화면의 미션 진행도가 실시간으로 업데이트되는가? (5초 간격)
  - 산책 완료:
    - "산책 종료" 버튼 클릭
    - 산책 요약 다이얼로그가 표시되는가? (걸음수, 시간, 거리, 간식, 경험치)
    - AI 대화 (walk_complete): 산책 완료 축하 메시지가 표시되는가?
    - "확인" 버튼 클릭 시 홈 화면으로 이동

  2.3 보상 시스템 테스트 (3분)

  - 간식 획득:
    - 300걸음 걸으면 간식 +1 획득하는가?
    - 홈 화면 펫 상태 위젯에 간식 개수 증가 확인
  - 간식 먹이기:
    - 홈 화면에서 "간식 주기" 버튼 클릭
    - AI 대화 (feed): 간식 먹는 반응 메시지가 표시되는가?
    - 간식 개수가 감소하는가?
  - 행복도 증가:
    - 500걸음 걸으면 행복도 +1 증가하는가?
    - 행복도 바가 업데이트되는가?
  - 행복도 낮음 알림:
    - (시간이 지나면) 행복도가 30 미만으로 떨어지면 AI 대화 (low_happiness) 메시지가 표시되는가?

  2.4 레벨 시스템 테스트 (2분)

  - 경험치 획득:
    - 산책 완료 시 경험치가 증가하는가?
    - 경험치 바가 채워지는가?
  - 레벨업:
    - 경험치가 100% 도달 시 레벨업 다이얼로그가 표시되는가?
    - AI 대화 (level_up): 레벨업 축하 메시지가 표시되는가?
    - 레벨업 보상 (간식 +5, 행복도 +20)이 지급되는가?
    - 레벨 숫자가 증가하는가? (Lv. 1 → Lv. 2)

  2.5 미션 시스템 테스트 (2분)

  - 미션 확인:
    - 홈 화면 미션 요약 위젯을 탭하면 미션 리스트 화면으로 이동하는가?
    - 일일 미션이 표시되는가? (예: "오늘 5,000걸음 걷기")
    - 주간 미션이 표시되는가?
    - 각 미션의 진행도 바가 표시되는가?
  - 미션 완료:
    - 미션 목표 달성 시 "완료" 뱃지가 표시되는가?
    - AI 대화 (mission_complete): 미션 완료 축하 메시지가 표시되는가?
    - 보상 (간식, 경험치)이 자동 지급되는가?

  2.6 배지 시스템 테스트 (1min)

  - 배지 화면 접근:
    - 홈 화면에서 배지 아이콘/버튼 클릭 시 배지 화면으로 이동하는가?
  - 배지 표시:
    - 10개 배지가 티어별로 그룹화되어 표시되는가? (Bronze, Silver, Gold, Platinum)
    - 해제되지 않은 배지는 회색/잠금 표시인가?
    - 해제된 배지는 컬러로 표시되는가?
  - 배지 진행도:
    - 각 배지의 진행도 (예: "15/100 걸음")가 표시되는가?
    - "첫 산책" 배지가 자동으로 해제되는가?

  🤖 Week 3: AI 통합 테스트 (10분)

  3.1 Firebase Remote Config 확인 (1분)

  - 앱 시작 시 로그 확인 (콘솔 또는 Xcode):
    - "Firebase Init Summary" 로그가 표시되는가?
    - Firebase Core: ✅
    - Remote Config: ✅
    - Analytics: ✅

  3.2 AI 대화 7가지 컨텍스트 테스트 (5분)

  - 1. greeting (인사):
    - 앱 시작 시 홈 화면에 펫의 인사 말풍선이 표시되는가?
    - 메시지가 자연스러운가?
  - 2. walk_complete (산책 완료):
    - 산책 종료 후 산책 완료 대화가 표시되는가?
    - 걸음수 데이터가 포함되어 있는가?
  - 3. mission_complete (미션 완료):
    - 미션 완료 시 축하 대화가 표시되는가?
  - 4. feed (간식 먹이기):
    - "간식 주기" 버튼 클릭 시 간식 먹는 반응 대화가 표시되는가?
    - 간식 개수가 언급되는가?
  - 5. level_up (레벨업):
    - 레벨업 시 축하 대화가 표시되는가?
    - 새 레벨 숫자가 언급되는가?
  - 6. low_happiness (행복도 낮음):
    - 행복도가 30 미만일 때 위로/격려 대화가 표시되는가?
  - 7. greeting_static:
    - 홈 화면 인사가 시간대별로 다르게 표시되는가(풀벡메세지)?

  3.3 온라인 AI 응답 테스트 (2분)

  - WiFi 연결 상태:
    - WiFi 켜진 상태에서 AI 대화 요청
    - 응답 시간이 2-5초 이내인가?
    - 응답 메시지가 자연스럽고 컨텍스트에 맞는가?
    - 로딩 중 ShimmerLoading 애니메이션이 표시되는가?

  3.4 오프라인 폴백 테스트 (2분)

  - 비행기 모드 활성화:
    - 설정 앱에서 비행기 모드 켜기
    - WalkDog 앱으로 돌아오기
  - 폴백 응답 확인:
    - "간식 주기" 버튼 클릭 시 즉시 응답하는가? (0-2ms)
    - 응답 메시지가 규칙 기반으로 생성되는가?
    - 앱이 프리징되지 않는가?
  - WiFi 재연결:
    - 비행기 모드 끄기
    - 다시 AI 대화 요청 시 온라인 응답으로 전환되는가?

  📊 추가 기능 테스트 (5분)

  4.1 통계 및 차트 (2분)

  - 일일 통계 카드:
    - 오늘의 걸음수, 거리, 시간, 산책 횟수가 표시되는가? - yes
  - 주간 차트 (막대 차트):
    - 최근 7일간의 걸음수가 막대 그래프로 표시되는가? - yes
    - 각 날짜 라벨이 표시되는가? - yes
  - 월간 차트 (라인 차트):
    - 최근 30일간의 걸음수가 라인 그래프로 표시되는가? - yes
    - 차트를 스크롤할 수 있는가? - yes

  4.2 연속 산책 추적 (1min)

  - 연속 산책 위젯:
    - "🔥 연속 X일" 메시지가 표시되는가? - yes
    - 최장 연속 기록이 표시되는가? - yes

  4.3 GPS 실외 모드 (2분)

  - 실외 판정:
    - 실제로 밖으로 나가서 산책 시작 - yes
    - GPS 상태 위젯에 "실외" 또는 정확도 표시되는가? - ?
    - 실외 보너스 (1.5배) 적용되는가? - ?
  - 이동 거리 계산:
    - 산책 완료 시 이동 거리가 계산되는가? - no
    - 평균 속도가 계산되는가? - no

  ✅ 테스트 완료 후 확인사항

  성능 체크

  - 앱이 3초 이내에 시작되는가? - yes
  - 화면 전환이 부드러운가? - yes
  - 메모리 사용량이 200MB 이하인가? (설정 → 일반 → iPhone 저장공간) - yes
  - 배터리 소모가 과도하지 않은가? - yes

  안정성 체크

  - 앱이 크래시 없이 안정적으로 동작하는가? - yes
  - 백그라운드에서 돌아왔을 때 상태가 유지되는가? - yes
  - 다크 모드 전환 시 UI가 깨지지 않는가? - yes

  데이터 체크

  - 앱을 종료하고 재시작해도 펫 정보가 유지되는가? - yes
  - 걸음수, 간식, 행복도 데이터가 정확한가?
  - 미션 진행도가 정확하게 저장되는가?
